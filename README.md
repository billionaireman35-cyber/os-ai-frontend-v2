# OS AI Frontend

React + Vite frontend for OS AI.

## Features
- Clean, dark design with glass‑morphism
- Authentication (login, register)
- AI chat with model selection (tier‑based)
- Vault (wallet, swap, send, Safe)
- Pulse (news, token search, live DexScreener feed)
- Hustle Hub (collaborative workspaces)
- Founder Sanctum (admin dashboard)
- User profile with name editing

## Setup
1. Copy `.env.example` to `.env` and set `VITE_API_URL`.
2. Install dependencies: `npm install`
3. Run: `npm run dev -- --host`

## Deployment
Build: `npm run build`
Output: `dist/` – deploy to Cloudflare Pages or any static host.
